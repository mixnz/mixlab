# AGENTS.md

This repository's rules for coding agents live in [CLAUDE.md](CLAUDE.md), whatever the agent. Read
it first: it says what MixLab and MixEngine are, the non-negotiable rules, and the commands. Working
in `apps/desktop/`, read [apps/desktop/CLAUDE.md](apps/desktop/CLAUDE.md) as well.

Procedures for recurring work — what to check before pushing, a red CI job, a test that starts a
program, text a user reads, CSS, shared components, this machine's shells — are in
[.claude/skills/](.claude/skills/), one `SKILL.md` each. The description at the top of each says
when it applies.

All design detail is under [docs/](docs/README.md).
